# 1. VISION GLOBALE

Refondre entièrement l’application **BMC Community Manager AI** afin de créer une expérience digitale **exceptionnelle, ultra-premium, futuriste, immersive et visuellement spectaculaire**.

Je veux un résultat **OUT OF THIS WORLD**.

Il ne faut absolument pas produire un dashboard SaaS générique avec des cards standards, des tableaux basiques et des boutons classiques.

Le produit doit donner l’impression d’utiliser un véritable logiciel SaaS de nouvelle génération conçu pour des professionnels du Community Management.

L'expérience doit combiner :

**BMC + AI + Social Media + Industrial Design + Premium SaaS + Futuristic Motion Design + Creativity**

Le design doit être :

* spectaculaire ;
* élégant ;
* moderne ;
* intelligent ;
* immersif ;
* professionnel ;
* extrêmement fluide ;
* intuitif ;
* cohérent ;
* responsive.

Le résultat doit être suffisamment beau pour provoquer immédiatement un :

### "WOW."

Mais après le WOW, l'utilisateur doit ressentir :

### "C'est extrêmement simple à utiliser."
